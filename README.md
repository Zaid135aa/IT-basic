# Portfolio-website

Dit is een eenvoudige portfolio-website van Zaid Othman, gemaakt met HTML, CSS en JavaScript.
De website bestaat uit één pagina met drie secties: Over mij, Projecten en Contact.

## Projectstructuur

```
ITWeek2/
├── index.html      # Hoofdpagina met de drie secties
├── css/
│   └── style.css   # Opmaak en styling van de website
├── js/
│   └── script.js   # Interactieve functies (jaartal, smooth scrolling)
├── images/         # Afbeeldingen voor de website (leeg, klaar voor gebruik)
└── README.md       # Dit bestand
```

## Vereisten

- Een webbrowser (bijvoorbeeld Google Chrome, Firefox of Edge)
- Visual Studio Code (optioneel, om de code te bewerken)

## Hoe start je het project?

1. Open de map `ITWeek2` in Visual Studio Code.
2. Open het bestand `index.html` in een webbrowser (dubbelklik of rechtermuisknop > Openen met).
3. De website wordt nu in de browser weergegeven.
